# radhey
## 3D hotel construction animation

Open `hotel-construction/index.html` in a browser (needs internet for three.js from jsDelivr).
A 42-second loop: excavation → foundation → tower crane → 12 floors (columns, crane lift, slab) →
glazing → roof & sign → crane/scaffold removal → landscaping → dusk with lights on.
Controls: play/pause, scrub, speed, auto-rotate; drag to orbit, scroll to zoom.
